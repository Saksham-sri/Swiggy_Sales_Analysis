# Swiggy Sales Analysis using Python

## Project Overview
This project focuses on analyzing Swiggy restaurant sales data using Python.  
The analysis includes data cleaning, exploratory data analysis (EDA), visualization, and extracting business insights from the dataset.

The main objective of this project is to understand:
- Customer ratings behavior
- Food category performance
- Sales trends
- Price vs Rating relationship
- Restaurant insights using data visualization

---

## Dataset
The dataset contains information related to:
- Restaurant names
- Food categories
- Prices
- Ratings
- Order dates
- City details

---

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

---

## Project Workflow

### 1. Data Loading
- Imported dataset using Pandas
- Checked dataset structure and datatypes

### 2. Data Cleaning
- Handled missing values
- Removed duplicates
- Converted date columns
- Fixed inconsistent data

### 3. Exploratory Data Analysis (EDA)
Performed analysis on:
- Top food categories
- Highest rated food items
- Daily sales trends
- Price vs Rating correlation
- Average ratings by category

### 4. Data Visualization
Created visualizations using:
- Bar Charts
- Scatter Plots
- Count Plots
 

---

## Key Insights
- Most food categories have ratings between 3.5 and 5.
- Price does not strongly affect customer ratings.
- Some affordable food categories also receive high ratings.
- Sales trends vary across different days.
